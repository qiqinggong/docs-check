# 配置契约

项目维护规则与扫描范围，工具只支持以下根配置子集，不声称兼容 Markdownlint CLI2 的全部功能。

## 格式与范围

`.markdownlint-cli2.jsonc` 支持 JSONC 注释和尾逗号，允许 `globs`、`config` 和可选的 `fix: false`：

```json
{
  "globs": ["README.md", "docs/**/*.md"],
  "fix": false,
  "config": {"default": true, "MD013": false, "MD060": false}
}
```

`globs` 是项目相对的 Markdown 文件模式，支持否定模式；范围为空或越出项目时报错，不跟随符号链接，包括固定目录前缀和中间目录中的链接。格式与链接检查使用同一组扫描文件，已选定的文件路径不再作为 glob 展开。

规则按随 Markdownlint 提供的严格 schema 校验。不读取其他忽略文件、子目录配置或项目 npm 依赖；不支持外部继承、修复选项或未知配置。新增能力需同时更新契约与回归。

## GFM 与本地链接

`.remarkrc.json` 声明：

```json
{
  "plugins": [
    "remark-gfm",
    ["remark-validate-links", {"repository": false}]
  ]
}
```

插件从工具自身安装包加载，`remark-gfm` 可携带原生选项。两项插件均为必需能力，不能用 `false` 选项禁用。检查本地文件、中文与其他标题锚点、表格链接及引用标签；不验证远端网址可用性。链接目标可能作为校验输入被读取，不能将扫描范围等同于所有可读取目标的完整清单。

项目内容和本地链接应来自自有受控资料。不向配置加入本机认证或无关目录。

## 结果与退出码

| 情况 | 退出码 | 含义 |
| --- | --- | --- |
| 完成检查且通过 | `0` | `passed` |
| 规则违反 | `1` | `violations`，提供诊断 |
| 参数、配置或已启动 CLI 的环境失败 | `2` | `unavailable`，不能记为检查通过 |
| 帮助、版本或列举成功 | `0` | 只完成相应操作，不代表检查通过 |

Node 缺失等导致 CLI 无法启动时，由系统报告实际错误和退出码，不保证 JSON 输出或退出码 `2`。

`--json` 提供工具与引擎版本、目标根、文件集、状态、诊断和退出码。`--version` 报告实际安装的组合。默认根为调用者当前目录，`--root` 显式指定目标，不寻找相邻项目或 Git 主工作树。

自动检查只证明实际覆盖的规则满足，不能替代内容、业务或人工验收。消费项目可记录经验证的发行基线；是否作为强制准入由项目独立决定。
